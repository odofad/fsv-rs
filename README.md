# fsv-rs
Rust rewrite of fsv (3D File System Visualizer). Target: Ubuntu 24.04+ with Bevy/wgpu (Vulkan). Phases: 0) scanner + data model, 1) MapV treemap layout + basic 3D view, 2) TreeV radial platforms, 3) interaction (picking + egui side panel), 4) polish (colors, labels, performance), 5) cargo-deb packaging. Inspired by the Jurassic Park fsn/fsv tool.
